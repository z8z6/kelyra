# Kide

- Run VS Code validation and packaging commands from `vscode/`.
- Validate VS Code changes with `npm test` in `vscode/`.
- Package the VS Code extension under `vscode/build/`.
- Run JetBrains packaging commands from `jetbrains/`, with output under
  `jetbrains/build/distributions/`.
- Do not commit generated `build/`, `node_modules/`, or VSIX files.

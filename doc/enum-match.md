# 枚举、match 与块表达式

首版 `enum` 是有独立类型身份的纯枚举值，没有关联数据。底层类型默认是 `i32`，也可指定整数类型。成员可以显式给出由整数字面量、先前成员和算术运算组成的编译期整数表达式；未指定的成员从零开始，或接续前一个成员加一。名称、数值重复及超出底层类型范围都会报错。

```kelyra
enum Color: u8 {
  Red,
  Green = 3,
  Blue, // 4
}

fn color_code(color: Color) -> i32 {
  return match color {
    Color.Red => 1,
    Color.Green => { let code: i32 = 2; code },
    Color.Blue => 3,
  };
}
```

枚举成员使用 `Color.Red`。不同枚举之间不能隐式互换，枚举与整数也不能隐式互换。支持同一枚举类型的 `==`、`!=`；使用 `color as u8` 显式转为整数。整数转枚举暂不支持，因为整数可能不是有效成员。若枚举没有零值成员，变量和无显式构造函数的字段不能靠零初始化。

`match` 是表达式，求值一次被匹配对象，只执行命中的分支。可匹配本地枚举、`bool` 与整数（包括由 C 枚举导入的整数类型）。枚举和布尔值必须覆盖全部成员或使用 `_`；整数必须有 `_`。重复或无法到达的分支报错。所有分支的结果类型须一致。

`{ ... }` 可作块表达式；末尾没有分号的表达式是块的结果。没有尾表达式时结果为 `void`。块内声明的变量只在该块中可见。

```kelyra
let category: i32 = match number {
  0 => 0,
  1 => 1,
  _ => { let fallback: i32 = 2; fallback },
};
```

注解参数也可声明为枚举类型。`std.annotation.Layout` 定义 `System` 与 `C`，例如 `@layout(Layout.C)`。枚举参数只接受该枚举已声明的成员。

首版不提供携带数据的枚举成员、模式绑定、守卫与范围模式。C 导入的枚举保持开放的整数类型，故其 `match` 仍需要 `_`。
